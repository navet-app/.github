# Contributing to Navet

Thanks for helping improve Navet. Choose the repository that owns your change:

- [navet](https://github.com/navet-app/navet): the dashboard, provider adapters, apps, and documentation.
- [navet-cards](https://github.com/navet-app/navet-cards): custom Home Assistant dashboard cards.
- [navet-home-assistant](https://github.com/navet-app/navet-home-assistant): generated Home Assistant integration packaging. Make integration changes in the [Navet source](https://github.com/navet-app/navet/tree/main/platform/home-assistant).

Read the repository's contribution and development guides before changing code. Search existing issues, describe reproducible bugs with version and installation details, and discuss substantial changes before implementation. Keep pull requests focused and include relevant validation.

For questions and ideas, join [Discord](https://discord.gg/fJWZwSyfVf), [r/navet](https://www.reddit.com/r/navet/), or [GitHub Discussions](https://github.com/navet-app/navet/discussions).

Report vulnerabilities privately following our [security policy](SECURITY.md). All community participation follows our [Code of Conduct](CODE_OF_CONDUCT.md).
