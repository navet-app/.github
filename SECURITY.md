# Security policy

Report suspected vulnerabilities in Navet projects privately to **security@navet.app**. Please include the affected repository and version, installation mode, reproduction steps, and potential impact. Keep provider credentials and personal data out of public issues.

Maintainers investigate reports and coordinate fixes and disclosure. Please allow time to validate and address the issue before publishing details.

See the [Navet security policy](https://github.com/navet-app/navet/blob/main/SECURITY.md) for dashboard deployment guidance.
