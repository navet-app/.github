# Getting help with Navet

Start with the [documentation](https://docs.navet.app/) for installation, configuration, and troubleshooting.

For questions and help from the community, use [GitHub Discussions](https://github.com/navet-app/navet/discussions) or [Discord](https://discord.gg/fJWZwSyfVf). Include your Navet version, connected provider, installation method, and the steps you have tried.

## Report a bug

Search existing issues, then report the problem in the repository that owns it:

- [Navet](https://github.com/navet-app/navet/issues): dashboard, provider adapters, documentation, and Home Assistant integration behavior.
- [Navet Cards](https://github.com/navet-app/navet-cards/issues): custom Home Assistant dashboard cards.
- [Home Assistant packaging](https://github.com/navet-app/navet-home-assistant/issues): installation or distribution problems with the packaged integration.

Include steps to reproduce, expected and actual behavior, and relevant logs or screenshots. Remove credentials and personal information before sharing.

## Suggest an improvement

Use [Navet Discussions](https://github.com/navet-app/navet/discussions) or [Navet Cards Discussions](https://github.com/navet-app/navet-cards/discussions) to explain the problem you want to solve and discuss possible approaches.

## Report a security vulnerability

Report vulnerabilities privately to **security@navet.app**. Follow the [security policy](https://github.com/navet-app/.github/blob/main/SECURITY.md).
